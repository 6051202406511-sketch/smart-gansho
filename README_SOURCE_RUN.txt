入学願書AI-OCR ソース実行版
==========================

このフォルダーの START_APP.bat から、Pythonソースを直接起動できます。
インストーラーやEXEは使いません。既存の SchoolApplicationOCR.exe は変更しません。

必要なもの
----------
- Windowsにインストール済みのPython（3.11～3.13を推奨。Tcl/Tkを含むもの）
- requirements.txt に記載されたPythonライブラリ

ライブラリが未導入の場合、START_APP.bat は自動インストールしません。
インターネット接続とインストール権限がある環境で、コマンドプロンプトを
このフォルダーで開き、次のコマンドを実行してください。

    py -m pip install -r requirements.txt

その後、START_APP.bat をダブルクリックします。Pythonや必要ライブラリが
既にないPCでは、このソース実行版だけでは起動できません。

OCRとデータ
-----------
- RapidOCRが既定です。Ollamaはアプリ画面から明示的に選び、別途手動準備した
  場合のみ使用します。アプリはOllamaやモデルを自動取得しません。
- OCR処理はローカルで行います。画像を外部サービスへ送信しません。
- 読み取り結果は必ず原本と照合してください。特に個人情報を含む実書類を
  初回テストに使わないでください。
- 名簿や一時データの保存・削除については、README_USER.txt の注意事項も
  確認してください。
