入学願書AI-OCR Windows版
========================

【インストールと起動】
1. 配布されたZIPを右クリックして「すべて展開」します。ZIPの中から直接使わないでください。
2. 展開したフォルダーの Install.bat をダブルクリックします。管理者権限は不要です。
3. デスクトップまたはスタートメニューに作られた「School Application OCR」から起動します。
4. 名簿は「ドキュメント\SchoolApplicationOCR」に保存されます。アプリ画面で別の保存先も選べます。

Pythonのインストールは不要です。最初の起動は少し時間がかかることがあります。
Windowsの警告が表示された場合は、配布元を確認してから実行してください。

【OCR方式について】
- 初期設定はRapidOCRです。Ollamaなど追加のOCRソフトを入れなくても、アプリをインストールした直後から使えます。OCR結果は必ず原本と照合してください。
- 精度比較用の任意機能として、アプリ下部からOllamaも選べます。OllamaはPC内だけで動作し、画像を外部サービスへ送信しません。使用するにはOllama公式サイト `https://ollama.com/download` から手動でインストールし、PowerShellで `ollama pull gemma4:e2b` を実行してください（約4.6GB。ダウンロードにインターネット接続と空き容量が必要です）。アプリはOllamaやモデルを自動インストール/ダウンロードしません。
- 開発PCのOllama `0.40.16`と`gemma4:e2b`では、個人情報のない印刷日本語合成画像1枚の氏名・フリガナ・生年月日・出身校を正しく読み取りました。別の合成画像ではOllamaが4/4（約38.5秒）、RapidOCRが3/4（約3秒、フリガナ空欄）でした。1枚ずつの合成画像だけの結果であり、実際の願書や手書き文字の精度は未検証です。
- Ollama使用時は数十秒から数分かかることがあり、最大240秒でタイムアウトします。読み取り方式は画面下部で選べます。方式変更時、画像を読み込み済みなら現在の入力を置き換える前に確認します。
- AIの読み取り結果に誤りがない保証はありません。すべての項目が黄色の「要確認」になるため、必ず原本を見て修正してください。

【読み取りやすい写真の撮り方】
- 書類全体を画面に入れ、四隅が切れないように撮影してください。
- できるだけ真上から撮り、紙の面とカメラを平行にしてください。
- 明るい場所で、影・反射・ぼけがない状態にしてください。
- 小さな文字がある場合は、書類に近づきすぎずピントを合わせて撮ってください。
- OCRは読み間違えることがあります。読み取り後は、すべての項目を原本と見比べてください。
- 黄色の「要確認」は、特に読み取り精度が低い項目または空欄です。原本を見て修正してから保存してください。
- 画像から読み取った内容を保存するときは、確認画面で全項目を原本と照合したことを確認してください。

削除するときは、配布ZIPを展開したフォルダーにある Uninstall.bat を実行してください。保存済みのExcel名簿と、別途インストールしたOllama・モデルは削除されません。

【個人情報の取り扱い】
- OCR結果は必ず書類と見比べ、確認・修正してから保存してください。
- 最初は個人情報を含まないテスト画像を使ってください。
- 写真の削除を試みますが、SSD、同期、バックアップ等からの完全消去は保証できません。
- スマートフォン連携は同一LAN内のHTTP通信で、暗号化されません。信頼できるネットワークでのみ使ってください。

この配布物は試用版です。全PCでの動作、提出要件への適合、OCR精度は保証されません。
